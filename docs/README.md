## Documentation Standards

All documentation in this folder follows these principles:

1. **Clear and Concise**: Get to the point quickly
2. **Example-Driven**: Show, don't just tell
3. **Up-to-Date**: Update docs when changing code
4. **Searchable**: Use clear headings and keywords
